# 🌐 Personal Developer & Portfolio Platform

A modern, responsive single-page personal developer portfolio built with **HTML5**, **Tailwind CSS**, and custom **Blogger XML templates**.

---

## 📌 Project Overview
- **Zero Server Cost:** Hosted directly on Google Blogger’s reliable global CDN infrastructure.
- **Mobile-First Responsive:** Structured with Tailwind CSS utility classes and mobile viewport meta tags to prevent horizontal overflow.
- **Clean Architecture:** Semantic XML/HTML template integration tailored for showcasing AI/ML projects and data analytics skills.
- **High Performance:** Lightweight assets ensuring quick load times across both mobile and desktop viewports.

---

## 🛠️ Tech Stack
- **Markup:** HTML5, Blogger XML Template
- **Styling:** Tailwind CSS (Utility-First Grid & Flexbox)
- **Icons & UI:** FontAwesome
- **Live Deployment:** [virajkr.blogspot.com](http://virajkr.blogspot.com)
